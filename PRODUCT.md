# Porchlight product

<!-- impeccable:product-schema 1 -->

## Platform

ios

## Users

Older adults living alone use their own iPhone for daily check-ins, upcoming plans, contacting family and asking for help. Family and trusted neighbors coordinate follow-through from a separate experience. The volunteer desk remains a secondary sample experience.

## Product Purpose

An AI daily conversation turns expressed needs into visible requests, family tasks and updates. The user confirmed that the older person's Today screen should prioritize the next step and a large check-in action, with simple Plans and Family navigation. The family experience should make attention and ownership easy to see.

## Capabilities and Constraints

Existing Expo SDK 57 / React Native application, running in Expo Go, backed by the existing Node API. Preserve existing check-in, speech, scam, help, task handoff, story, schedule and ride flows. Voice input uses keyboard dictation. The senior confirms a real ride through the Uber link; Porchlight simulation states never establish a real booking. Empty-environment demo operation is required. No new server data contracts in this redesign. The user authorized pushing the redesign and creating a PR after reviewing the local preview.

## Brand Commitments

Porchlight name and lamp. Quiet neutrals, hairline borders and soft depth; lamp is the bold accent. Red is reserved for help and scams. Atkinson Hyperlegible for the older person, system type for family, SF Symbols and Reanimated with Reduce Motion support. Plain, warm sentence-case copy.

## Evidence on Hand

PLAN.md, TEAM_PLAN.md, existing mobile flows and server contracts. Demo people and organizations are fictional and labeled sample. No native screenshot or physical-device evidence is currently available on this Windows workstation.

## Product Principles

- Make the next action obvious without overwhelming the older person.
- Keep the older person informed before family, and keep their choices visible.
- Report confirmed facts, requests and simulations distinctly.
- Identify the AI; never request money, codes, passwords or ID numbers.
- Do not diagnose or imply that a missed call is proof of an emergency.

## Accessibility & Inclusion

Senior text at least 20pt, large actions at least 104pt tall, labeled VoiceOver controls and scalable text. Native safe areas, clear navigation, no animated tab switches. Family controls at least 44pt. Verify iOS export and report any unavailable native validation honestly.
